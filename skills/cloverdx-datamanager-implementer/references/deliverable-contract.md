# Deliverable Contract

Canonical implementation files:

- `customization/data-manager/app.js` for behavior
- `customization/data-manager/app.css` for presentation

Edit these files directly. Do not create mirror/review/export copies unless the
user explicitly asks.

Extra shipped assets are allowed only when needed, and must live under
`customization/data-manager/`.

`output/customization.zip` is generated output. Do not edit it directly; fix
source under `customization/data-manager/` and regenerate the ZIP.

`.work/` is scratch for inspection, extracted files, notes, and experiments.
Never put scratch data under `customization/` or ship it in the ZIP.

## Delivery Summary

At the end of the task, summarize:

- Which pages or hooks were customized
- Whether live inspection was used
- Any assumptions or known fragility
